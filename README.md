# Homebrew tap for Lucium

[Lucium](https://lucium.app/) is a free web browser for Mac (Apple silicon, macOS 13 or later), with a vertical sidebar and one space for each part of your life. It is free software (GPL-3.0-or-later).

```sh
brew install --cask pOwn3d/lucium/lucium
```

- The cask installs the disk image that lucium.app serves, checked against its published SHA-256 sum. Lucium then updates itself (`auto_updates true`).
- The source code of Lucium: <https://github.com/pOwn3d/Lucium>.
- Questions and reports: contact@lucium.app.
